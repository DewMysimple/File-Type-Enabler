# 当前状态

## 项目目标与阶段

- File Type Enabler 是 Obsidian 桌面插件。v0.1.0 在原生文件浏览器里显示 `.html`、`.htm`、`.epub`、`.xmind`，三个格式开关默认开启并按 Vault 保存。初始需求见 [开发任务](../../prompt/1.txt)，当前版本以 [manifest](../../manifest.json) 为准。

## 关键入口与运行命令

- [插件入口](../../src/main.ts) 管理视图与设置生命周期。[格式和设置](../../src/settings.ts) 定义扩展名及默认值，[设置页](../../src/settingsTab.ts) 使用 Obsidian 原生控件。
- [文件浏览器兼容层](../../src/fileExplorer.ts) 对已加载的目录视图实例应用过滤与刷新。停用时归还本插件替换的方法。文件识别与打开沿用 Obsidian 的原生路径。
- 使用 Node.js 18+。执行 `npm ci` 安装依赖、`npm run typecheck` 检查类型、`npm run build` 生成发布产物。开发监听 `npm run dev` 在 `.dev/obsidian-file-type-enabler/` 提供开发安装文件。安装和开发说明见 [项目 README](../../README.md)。

## 约束与已确认选择

- 插件范围是目录显示。原始文件由 Vault 和用户管理，阅读与编辑使用 Obsidian 现有视图、系统应用或其他插件。
- 2026-11-25 用户指定 [GitHub 远程仓库](https://github.com/DewMysimple/File-Type-Enabler) 并授权持续交付。每次有工程改动的完整开发对话都需提交并推送。最新版本同时保留于 `dist/obsidian-file-type-enabler/` 和对应版本的 ZIP。详细规则见 [根指令](../../AGENTS.md)。

## 当前进度与已知问题

- v0.1.0 的过滤、设置持久化和停用恢复已实现。目录层依赖 Obsidian 内部方法，客户端升级或与其他修改目录项的插件共用时可能需要复测。遇到兼容提示时，可停用插件并临时使用 Obsidian 的全局“显示所有文件类型”选项。
- 发布目录中的解压文件夹可直接复制到 Vault 的 `.obsidian/plugins/`。[构建入口](../../esbuild.config.mjs) 将同一次编译结果交给 [发布脚本](../../scripts/write-release.mjs)，生成可安装目录和按版本命名的 ZIP。

## 恢复位置与下一步

- 迭代先检查 `git status --short --branch` 和上游。格式行为改动从 [格式配置](../../src/settings.ts) 与 [文件浏览器兼容层](../../src/fileExplorer.ts) 起步。
- 版本发布前同步包版本、重新执行构建，核对 `dist/` 里最新解压目录和同版本 ZIP，再按 [根指令](../../AGENTS.md) 提交、推送与校验远端引用。
