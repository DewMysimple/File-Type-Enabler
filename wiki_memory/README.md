# 工程记忆导航

采用 `lite` 布局。由 Codex 根据单一桌面插件的工程规模选择，一页状态可以覆盖源码、发布、约束和接续位置。当前模式以 `.memory.json` 为准。

先读项目根指令和记忆维护协议，按下方索引进入当前状态。需要追溯变更与验证时，查阅工作日志。

日常开发直接遵循项目内协议，不调用 wiki-memory Skill；仅用户明确要求记忆管理时使用 Skill。
