# 项目名称：Obsidian File Type Enabler

你是一名资深 Obsidian 插件开发工程师，精通 TypeScript、Obsidian Plugin API、Node.js 和 Electron。

请直接在当前工作目录中开发一款完整、可运行、可安装的 Obsidian 插件。

## 一、项目目标

开发一款轻量级 Obsidian 插件，让 Obsidian 能够在左侧文件浏览器（File Explorer）中识别并显示用户指定的非原生文件格式。

第一版只支持以下格式：

- HTML：`.html`、`.htm`
- EPUB：`.epub`
- XMind：`.xmind`

本插件的唯一核心目标是：

**让上述文件能够正常出现在 Obsidian 左侧文件目录中，并且允许用户在插件设置中独立开启或关闭每种格式的识别功能。**

注意：本项目不开发文件阅读器，不开发文件预览器，不解析文件内容，不进行格式转换。

## 二、核心功能需求

### 1. 文件格式识别

插件默认支持以下扩展名：

| 格式 | 扩展名 |
|---|---|
| HTML | html、htm |
| EPUB | epub |
| XMind | xmind |

要求：

1. 插件能够识别 Vault 中对应扩展名的文件。
2. 文件能够正常出现在 Obsidian 左侧 File Explorer 中。
3. 文件名称、所在目录和扩展名应正确显示。
4. 支持 Vault 根目录以及任意层级的子目录。
5. 支持中文文件名、空格文件名及特殊字符。
6. 不修改原始文件。
7. 不影响 Markdown 文件及其他 Obsidian 原生文件的正常显示。

### 2. 独立开关设置

创建插件设置页面。

设置页面包含三个独立的开关：

- HTML 文件识别
- EPUB 文件识别
- XMind 文件识别

默认状态全部开启。

用户可以分别关闭某一种格式，而不影响其他格式。

例如：

- HTML：开启
- EPUB：关闭
- XMind：开启

此时 HTML 和 XMind 文件应该显示在文件目录中，EPUB 文件则不应该显示。

开关状态需要持久化保存。

要求：

1. 使用 Obsidian Plugin API 的 loadData() 和 saveData() 保存配置。
2. 插件重新加载后恢复之前的设置。
3. 用户切换开关后及时生效。
4. 不应要求用户手动修改配置文件。
5. 不应因为某一种格式关闭而影响其他格式。

### 3. 文件目录实时更新

当用户切换某种格式的开关时：

- 开启：对应格式的文件出现在文件目录中。
- 关闭：对应格式的文件从文件目录中隐藏。
- 再次开启：对应文件重新显示。

尽可能使用 Obsidian 官方支持的 API 实现文件过滤与目录刷新。

不要通过直接修改 Obsidian 内部 DOM 的方式实现。

不要使用脆弱的 CSS 隐藏文件。

不要通过修改 Obsidian 安装目录、核心文件或数据库实现。

如果官方 API 无法直接实现文件目录的扩展名过滤，请先研究可行的兼容方案，并说明限制。禁止通过虚假的注册或无效代码宣称功能已经完成。
